AlmaAPITK chunk pipeline: rebuild or retire?

Evidence from origin/main at de2013d (2026-09-02), gathered 2026-10-07 after the babysitter plugin was uninstalled.
Recommendation: Option B. Retire the orchestrated pipeline, and keep the parts that actually caught bugs. The live SANDBOX tests and the swagger error-code tool earned their keep. The orchestration layer around them caused most of the incidents and hasn't been used since July 22. Rebuilding it without babysitter would mean re-creating the most expensive part of the system for a working style you no longer use.

What the record shows

Earned its keep

  • SANDBOX live tests (59 files) caught real API-shape bugs: the user_note PUT shape (#119), user delete returning 204 rather than 200, update_letter needing an XML body (#114), RS citation codes (#194), and a borrowing-request 500 (#207).
  • regression-smoke flagged two failing suites, fixed in #213.
  • Batching worked during the May burst: 18 chunks in 15 days.

Cost more than it gave

  • Orchestration upkeep: about 6 pipeline-fix PRs (#91, #98, #102, #106, #182, #203).
  • Phantom merge: an empty implementation passed all 4 gates (#203).
  • Run hygiene: 20 runs stuck as "active", and up to 4 duplicate runs per chunk.
  • Gaps the gates let through, found in a release review: a bare except, a logger never fixed despite 7 chunks touching it, and four version bumps in one cycle.
  • Run-log metrics are empty: attempts is never filled in and time_s is always 0.
  • Deny-paths guard: blocks only .github/ and secrets/, with no recorded trigger.

How work actually happens now

  • Bug fixes have mostly bypassed the pipeline all along: #146, #154, #166, #177, #209, #214.
  • The last 3 merged PRs and the 0.5.1 release (2026-09-02) were all done directly.
  • Plain Claude Code subagents already cover the implement-then-review loop, with no separate harness to maintain.

What Option B means in practice

Keep and relocate

  • Move chunks/*/sandbox-tests/ to tests/sandbox/, and keep regression_smoke.py as a plain runner.
  • Keep scripts/error_codes/, and move its test from tests/agentic/ to tests/unit/.
  • Keep the R10 convention: tests/unit/regressions/.
  • Fold chunks-backlog.yaml groupings into GitHub milestones or labels.
  • Replace guardrails.json with Claude Code permission deny rules for the same two paths.

Remove

  • .a5c/, the /chunk-run-* commands, and the chunks CLI state machine
  • reconcile.py and its pipeline-only regression test
  • The SessionStart hook and CLAUDE.md's session-start protocol (about 67 lines)
  • The rest of scripts/agentic/ and tests/agentic/

Archive, don't delete

  • AGENTIC_RUN_LOG.md, AGENTIC_ORCHESTRATION_HANDBOOK.md, CHUNK_PLAYBOOK.md, ISSUE_PIPELINE.md: move to docs/archive/
  • The chunks/* manifests: archive alongside them as history
Estimated effort: one PR, about 59 test files moved plus the CI path updates. main deploys to DevSandbox only. AlmaAPITK has no prod branch.
